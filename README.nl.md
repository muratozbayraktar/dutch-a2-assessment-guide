# Beoordelingsgids Nederlands A2

## Spreken A2

### Adequaatheid/Begrijpelijkheid

| Score | Omschrijving |
| --- | --- |
| 0 punten | De uiting ontbreekt, is niet verstaanbaar of is geen antwoord op de vraag. |
| 1 punt | De uiting is een voorstelbaar, maar geen voor de hand liggend antwoord op de vraag en/of het antwoord is onvolledig of niet helemaal duidelijk. |
| 2 punten | De uiting is begrijpelijk en een adequaat antwoord op de vraag. |
| 3 punten | De uiting is helder en een uitstekend antwoord op de vraag. |

**Algemeen:** Indien adequaatheid/begrijpelijkheid 0 punten krijgt, worden de overige beoordelingsaspecten met een 0 beoordeeld.

### Woordgebruik

| Score | Omschrijving |
| --- | --- |
| 0 punten | Het woordgebruik beperkt zich tot woorden uit de opdracht en/of de woorden zijn verkeerd gebruikt. |
| 1 punt | Het woordgebruik is eenvoudig, bevat eigen woorden en de meeste woorden zijn goed gebruikt. |
| 2 punten | Het woordgebruik is gevarieerd en de meeste woorden zijn goed gebruikt. |

### Grammatica

| Score | Omschrijving |
| --- | --- |
| 0 punten | De uiting bevat veel grammaticale fouten. |
| 1 punt | De uiting bevat redelijk wat grammaticale fouten. |
| 2 punten | De uiting bevat nauwelijks of geen grammaticale fouten. |

### Vloeiendheid

| Score | Omschrijving |
| --- | --- |
| 0 punten | De uiting is in het geheel niet vloeiend en kenmerkt zich door veel lange pauzes en/of herformuleringen. |
| 1 punt | De uiting is enigszins vloeiend en bevat pauzes en/of herformuleringen. |
| 2 punten | De uiting is vloeiend. Pauzes en/of herformuleringen komen nog voor bij langere uitingen. |

### Coherentie

| Score | Omschrijving |
| --- | --- |
| 0 punten | De uiting vertoont geen samenhang. |
| 1 punt | De uiting vertoont enige samenhang, al dan niet bewerkstelligd door het gebruik van eenvoudige voegwoorden (zoals en, maar, want en omdat) en/of verwijswoorden (zoals hij, zij, die of dat). |

### Uitspraak

| Score | Omschrijving |
| --- | --- |
| 0 punten | De uiting is alleen met inspanning van een geoefende luisteraar verstaanbaar. |
| 1 punt | De uiting is zonder inspanning redelijk verstaanbaar voor een geoefende luisteraar. |
| 2 punten | De uiting is goed verstaanbaar, ook voor een ongeoefende luisteraar, ondanks een accent of af en toe een verkeerd uitgesproken woord. |

## Schrijven A2: Formulieren

### Adequaatheid/begrijpelijkheid

| score | omschrijving |
| --- | --- |
| 0 | De tekst is niet leesbaar en/of herkenbaar als uitwerking van de opdracht, of er is helemaal geen uitwerking. |
| 1 | De tekst is een voorstelbaar, maar geen voor de hand liggend antwoord op de vraag en/of het antwoord is onvolledig of niet helemaal duidelijk. |
| 2 | De tekst is acceptabel en herkenbaar als uitwerking van de opdracht. |
| 3 | De tekst is een uitstekende uitwerking van de opdracht. |

**Algemeen:** Indien adequaatheid 0 punten krijgt, worden de overige beoordeelaspecten met een 0 beoordeeld.

**Specifiek:** De tekst wordt beoordeeld als acceptabel (2 punten) wanneer: Hier wordt per opdracht een opdrachtspecifieke beoordeling aan toegevoegd.

### Spelling

| score | omschrijving |
| --- | --- |
| 0 | De tekst bevat zoveel spelfouten dat deze slechts met zeer veel moeite te lezen is en/of voldoet niet aan de beschrijving van 1 punt. |
| 1 | Persoonlijke gegevens zijn correct gespeld. Woorden en korte zinnen over alledaagse onderwerpen zijn (bijna altijd) correct overgeschreven. De spelling van korte woorden is fonetisch redelijk correct. |
| 2 | De spelling is vrijwel correct. Eventuele spelfouten tasten de begrijpelijkheid niet aan. |

### Woordgebruik

| score | omschrijving |
| --- | --- |
| 0 | Het woordgebruik omvat vrijwel alleen woorden uit de opdracht en/of sluit niet aan bij de opdracht. |
| 1 | Het woordgebruik is eenvoudig, redelijk gevarieerd en sluit aan bij de opdracht. |
| 2 | Het woordgebruik is gevarieerd en sluit aan bij de opdracht. |

## Examencijfer

De behaalde punten in de beoordelingsmodellen zijn ruwe beoordelingsscores; de ruwe score is niet hetzelfde als het uiteindelijke examencijfer. Zowel de actuele omzettingstabel van ruwe punten naar het examencijfer als de exacte slaaggrens in ruwe punten zijn onbekend. Het examencijfer of de zak-/slaaggrens kan daarom niet via een eenvoudige percentageberekening uit de ruwe scores worden afgeleid.
