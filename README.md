# Dutch A2 Assessment Guide

## Speaking A2

### Adequacy/Comprehensibility

| Score | Description |
| --- | --- |
| 0 points | The utterance is missing, is unintelligible, or is not an answer to the question. |
| 1 point | The utterance is a conceivable, but not an obvious answer to the question and/or the answer is incomplete or not entirely clear. |
| 2 points | The utterance is comprehensible and an adequate answer to the question. |
| 3 points | The utterance is clear and an excellent answer to the question. |

**General:** If adequacy/comprehensibility receives 0 points, the remaining assessment criteria are scored as 0.

### Vocabulary

| Score | Description |
| --- | --- |
| 0 points | The vocabulary is limited to words from the prompt and/or the words are used incorrectly. |
| 1 point | The vocabulary is simple, contains the candidate's own words, and most words are used correctly. |
| 2 points | The vocabulary is varied and most words are used correctly. |

### Grammar

| Score | Description |
| --- | --- |
| 0 points | The utterance contains many grammatical errors. |
| 1 point | The utterance contains a fair number of grammatical errors. |
| 2 points | The utterance contains hardly any or no grammatical errors. |

### Fluency

| Score | Description |
| --- | --- |
| 0 points | The utterance is not fluent at all and is characterized by many long pauses and/or reformulations. |
| 1 point | The utterance is somewhat fluent and contains pauses and/or reformulations. |
| 2 points | The utterance is fluent. Pauses and/or reformulations still occur in longer utterances. |

### Coherence

| Score | Description |
| --- | --- |
| 0 points | The utterance shows no coherence. |
| 1 point | The utterance shows some coherence, whether or not achieved through the use of simple conjunctions (such as *en* [and], *maar* [but], *want* [because/for], and *omdat* [because]) and/or reference words (such as *hij* [he], *zij* [she/they], *die* [that/those/who], or *dat* [that]). |

### Pronunciation

| Score | Description |
| --- | --- |
| 0 points | The utterance is intelligible only with effort from an experienced listener. |
| 1 point | The utterance is reasonably intelligible without effort for an experienced listener. |
| 2 points | The utterance is easily intelligible, including for an inexperienced listener, despite an accent or an occasionally mispronounced word. |

## Writing A2: Forms

### Adequacy/Comprehensibility

| Score | Description |
| --- | --- |
| 0 | The text is illegible and/or not recognizable as a completion of the task, or there is no response at all. |
| 1 | The text is a conceivable, but not an obvious answer to the question and/or the answer is incomplete or not entirely clear. |
| 2 | The text is acceptable and recognizable as a completion of the task. |
| 3 | The text is an excellent completion of the task. |

**General:** If adequacy receives 0 points, the remaining assessment criteria are scored as 0.

**Task-specific:** The text is assessed as acceptable (2 points) when: A task-specific assessment criterion is added here for each task.

### Spelling

| Score | Description |
| --- | --- |
| 0 | The text contains so many spelling errors that it can only be read with great difficulty and/or does not meet the description for 1 point. |
| 1 | Personal details are spelled correctly. Words and short sentences about everyday topics are (almost always) copied correctly. The spelling of short words is phonetically reasonably accurate. |
| 2 | The spelling is almost entirely correct. Any spelling errors do not affect comprehensibility. |

### Vocabulary

| Score | Description |
| --- | --- |
| 0 | The vocabulary consists almost exclusively of words from the prompt and/or does not fit the task. |
| 1 | The vocabulary is simple, reasonably varied, and fits the task. |
| 2 | The vocabulary is varied and fits the task. |

## Exam Grade

The points awarded across the rubric criteria are raw assessment scores, and are not the same as the final exam grade. Both the current conversion table used to translate raw rubric points into a final exam grade and the exact raw-point pass threshold are unknown. Consequently, a final exam grade or pass mark cannot be derived from the raw assessment points through a simple percentage calculation.
